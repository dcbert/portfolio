# Davide Bert — Portfolio

Single-page portfolio: systems that stay on your hardware.

**Live:** [dcbert.github.io/portfolio](https://dcbert.github.io/portfolio/)

## Stack

React · Vite · Tailwind v4 · GSAP ScrollTrigger · Lenis · lucide-react

## Develop

```bash
npm install
npm run dev
```

Build for GitHub Pages (`base: /portfolio`):

```bash
npm run build
```

Output lands in `dist/` and deploys via `.github/workflows/static.yml` on push to `master`.
